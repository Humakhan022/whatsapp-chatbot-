Connect Real WhatsApp to Your Bot

Deploy to Meta WhatsApp Cloud API or Twilio WhatsApp Sandbox

Your Live Server Webhook URL:
http://localhost:5000/webhook
Use ngrok http 5000 or cloudflared to get a public HTTPS URL for Meta/Twilio.
Meta Verify Token:
my_secret_whatsapp_verify_token_2026
  1. 1. Create Meta Developer App

    Go to developers.facebook.com > My Apps > Create App > Select Other > Business.

  2. 2. Add WhatsApp Product

    In the app dashboard, click Set Up WhatsApp. You'll receive a test phone number and a temporary access token.

  3. 3. Configure Webhook in Meta

    Under WhatsApp > Configuration, click Edit Webhook:

    • Callback URL: https://your-domain.ngrok-free.app/webhook
    • Verify Token: my_secret_whatsapp_verify_token_2026

    Subscribe to the messages field.

  4. 4. Put Tokens in .env file

    Add WHATSAPP_CLOUD_TOKEN and PHONE_NUMBER_ID to your .env file. Your bot will now automatically respond to real WhatsApp messages!

  1. 1. Open Twilio Console

    Go to console.twilio.com > Messaging > Try WhatsApp Sandbox.

  2. 2. Configure Sandbox Webhook

    Set "When a message comes in" URL to:

    https://your-domain.ngrok-free.app/twilio/webhook (HTTP POST).
  3. 3. Send WhatsApp Message to Sandbox Number

    Send the join code to Twilio's WhatsApp number. You'll immediately receive replies from your custom dataset bot!
